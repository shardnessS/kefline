# Неделя 0: упражнения

Семь маленьких задач. Тесты уже написаны, в коде заглушки с `panic`. Задача: сделать тесты зелёными, не трогая тестовые файлы.

| Папка | Что тренирует | Пригодится в |
|---|---|---|
| `01-errors` | ошибки вместо исключений: `errors.Is`, `errors.As`, обёртка через `%w` | везде |
| `02-interfaces` | интерфейсы без `implements`, указатели в методах, `errors.Join` | gateway, store |
| `03-workerpool` | горутины, `sync.WaitGroup`, ограничение параллелизма | ingest |
| `04-fanout` | каналы, закрытие каналов, раздача одного потока многим | gateway |
| `05-timeout` | `context`: таймаут и отмена, как не повесить горутину | везде |
| `06-boundedqueue` | очередь, которая не блокирует отправителя, а выбрасывает лишнее | очередь клиента в gateway |
| `07-conflation` | склейка изменений: для коэффициента важно только последнее значение | склейка в gateway |

Порядок важен: каждое следующее опирается на предыдущие.

```bash
go test ./learn/01-errors/          # одно упражнение
go test ./learn/...                 # все
go test -race ./learn/03-workerpool/  # с детектором гонок, нужен gcc (на Windows через MSYS2 или WSL)
```

Правила:
- Тестовые файлы `*_test.go` не меняй. Если кажется, что тест неправ, сначала обсудим.
- Подсказки в README каждой папки. Готовые решения не гугли, сначала попробуй сам, потом сравни с [Go by Example](https://gobyexample.com/).
- Решил — коммит с сообщением вида `learn: 01-errors`.
