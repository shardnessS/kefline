# 01. Ошибки

В Java ты бы бросил `IllegalArgumentException`. В Go функция возвращает ошибку вторым значением, а вызывающий проверяет `if err != nil`.

Задача: `ParseDecimal` разбирает десятичный коэффициент из строки.

- Пробелы по краям убрать, запятую считать точкой: `" 2,10 "` → `2.10`.
- Пустая строка: вернуть `ErrEmpty`. Это **sentinel-ошибка**, её сравнивают через `errors.Is`.
- Не число: вернуть ошибку `strconv.ParseFloat`, обёрнутую через `fmt.Errorf("...: %w", err)`. Тогда вызывающий достанет `*strconv.NumError` через `errors.As`. В тексте ошибки должна быть исходная строка.
- Коэффициент не больше 1 или больше 1000: вернуть `*RangeError` со значением. Это **своя ошибка-тип**, её достают через `errors.As`.

Что почитать: [Go by Example: Errors](https://gobyexample.com/errors), [Working with Errors in Go 1.13](https://go.dev/blog/go1.13-errors).

Аналогия с Java: sentinel-ошибка похожа на константу-исключение, своя ошибка-тип похожа на свой класс исключения с полями, `%w` похож на `cause`.
