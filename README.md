# kefline

Лента коэффициентов в реальном времени на Go. Как у букмекера, только данные синтетические.

**Статус:** в работе. Сейчас идёт неделя 0: основы Go, упражнения в `learn/`.

## Что будет внутри

```
симулятор ──► RabbitMQ ──► ingest ──► Redis (текущее состояние)
                              │   └─► PostgreSQL (история)
                              ▼
                       RabbitMQ fanout ──► gateway ──► WebSocket-клиенты
                                                 ▲
                         catalog (gRPC) ─────────┘ дерево и снимки
```

- **simulator** генерирует матчи, события в матче и смену коэффициентов.
- **ingest** проверяет порядок и дубли, держит дерево «спорт → турнир → матч → рынок → исход».
- **gateway** отдаёт клиенту снимок матча, потом только изменения. Медленные клиенты не тормозят остальных.
- **catalog** отдаёт дерево по gRPC.
- **loadgen** открывает тысячи клиентов и меряет задержку.

План по неделям: [docs/roadmap.md](docs/roadmap.md).

## Как запустить

Нужен Go (версия в `go.mod`). С недели 1 ещё Docker.

```bash
go test ./...                 # тесты
go test -race ./...           # тесты с детектором гонок (нужен gcc, в CI работает)
docker compose -f deploy/docker-compose.yml up -d   # RabbitMQ, PostgreSQL, Redis
```

Упражнения недели 0 по одному:

```bash
go test ./learn/01-errors/
```
